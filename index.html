تێبینی گرنگ: ئەم وەشانە dashboard ـێکی ناوخۆییە. هیچ نامەیەک بۆ AI نانێردرێت و هیچ کلیلی API لە براوزەر هەڵناگیرێت.

وەک هێرشکەر بیر بکەرەوە، وەک بەرگریکار کار بکە.

بابەتێک هەڵبژێرە. هەر یەکێکیان بنەما سەرەکییەکان، چۆنیەتی بەرگری، و شوێنی یاسایی بۆ تەمرین دەگرێتەوە.

تەنها لەسەر سیستەمی خۆت، ئامێری تاقیگە، یان ئامانجێک کە ڕێگەی نووسراوت بۆ هەیە تاقی بکەرەوە. دەستگەیشتنی بێ مۆڵەت لە زۆربەی وڵاتانی جیهاندا تاوانە.

بیدۆزەرەوە، بیسەلمێنە، ڕاپۆرتی بکە.

پڕۆگرامەکان شوێنگری بکە، ڕێڕەوێکی دووبارەبوونەوە بەکاربهێنە و ڕاپۆرتی ڕوون بنووسە. هەمیشە پابەندی scope ی هەر پڕۆگرامێک بە.

شوێنگری ئامانج

ڕێساکان پێش تاقیکردنەوە

    ڕێڕەوی گەڕان

    قاڵبی ڕاپۆرت

    ڕاپۆرتی Bug Bounty لە ئاستی نێودەوڵەتیدا دەخوێنرێتەوە، بۆیە ئەم قاڵبە بە ئینگلیزی دەمێنێتەوە.

    ئامرازە پارێزراوەکان

    ئەم شیکردنەوانە لە ناو براوزەرەکەتدا ئەنجام دەدرێن؛ هیچ داتایەک بۆ سێرڤەر نانێردرێت.

    ناسینەوە و دروستکردنی Hash

    دەقێک بنووسە بۆ دروستکردنی SHA-256، یان hash ـێک بلکێنە بۆ خەمڵاندنی جۆرەکەی. درێژی بە تەنها بەڵگەی یەکلاکەرەوە نییە.

    پشکنینی HTTP Security Headers

    هێدەرەکانی وەڵامی HTTP لێرە بلکێنە؛ تەنها بوونی هێدەر دەبینرێت، بەهای هەر هێدەرێکیش پێویستی بە پشکنینی زیاتر هەیە.

    شیکردنەوەی Content Security Policy

    ڕیزی CSP بلکێنە بۆ دۆزینەوەی چەند مەترسییەکی باو. ئەمە audit ـێکی سەرەتاییە، نەک پشکنینی تەواوی سیاسەت.

    گەڕان لە CVE / NVD

    ژمارەی CVE یان وشەی سەرەکی بنووسە. گەڕانەکە لە ماڵپەڕی فەرمی NVD دەکرێت.

    کردنەوەی گەڕانی NVD
    پێداچوونەوە بە CVSS، وەشانە کاریگەرەکان و ئاگادارییەکانی بەرهەمهێنەر بکە؛ تەنها ژمارەی CVE بڕیاری پاراستن نییە.

    کارەکانت پلان بکە.

    لیستێکی کورت لەوەی ئەمڕۆ گرنگە ڕابگرە. ئەرکەکان لەم براوزەرەدا هەڵدەگیرێن.
